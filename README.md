A doctor's note for GTA VI launch day: Dr. Ghost of make.fun diagnoses every GTA fan with severe Leonida fever and prescribes staying home until the credits roll. Thirteen years of waiting will do that to a person.

The meme itself is `meme.png` in this repository; `meme.html` is the page it was rendered from and `render.mjs` the script that rendered it. The entry hands in the address of the X post that carries the picture: `POST.json` names it, and `main.ts` copies that file to the grader's output folder.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
